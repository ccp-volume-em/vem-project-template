# Repository checks

These tests check the repository itself, not your analysis code: that project
files agree with each other (versions, changelog, links), that no data or large
files are committed, and that the template tools work.

They come from the project template. **Keep them**, and don't edit them here:
the `update-from-template` skill keeps them up to date. Tests of your own code
go in `tests/`, next to this folder.
