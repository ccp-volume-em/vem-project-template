# Data

Data are **not** stored in git: this folder is ignored except for this file.
Volume EM datasets are too large for git, and data may be unpublished or
restricted.

Describe here where the data live and how to get them, for example:

| Dataset | Where | Access | Persistent identifier |
| ------- | ----- | ------ | --------------------- |
| example | `python examples/make_example_data.py` | generated | — |

For sharing, deposit data in a public archive such as the
[BioImage Archive](https://www.ebi.ac.uk/bioimage-archive/) or
[EMPIAR](https://www.ebi.ac.uk/empiar/), preferably as OME-Zarr, and record
its DOI here. See `guidance/fair-data.md`.
